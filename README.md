# Minecraft Mob Helper Tool

A fun interactive CLI tool to help you and your kids learn about Minecraft mobs, calculate combat strategies, and plan XP farming!

## Features

- **Mob Encyclopedia**: Look up 20+ popular Minecraft mobs with detailed stats
- **Combat Calculator**: Find out how many hits you need to defeat any mob with your weapon
- **XP Calculator**: Plan your XP farming - calculate how many mobs to reach your target level
- **Search System**: Quick search to find mobs by name
- **Random Facts**: Get random mob information for fun learning

## Quick Start

### Run Interactive Mode:
```bash
python3 minecraft_mob_helper.py
```

### Quick Lookup (from command line):
```bash
python3 minecraft_mob_helper.py creeper
python3 minecraft_mob_helper.py ender dragon
python3 minecraft_mob_helper.py zombie
```

## What's Included

### Mob Categories:
- **Bosses**: Ender Dragon, Wither
- **Hostile Mobs**: Zombie, Creeper, Skeleton, Spider, Blaze, Ghast, Wither Skeleton, Guardian, Slime
- **Neutral Mobs**: Enderman, Wolf, Piglin, Iron Golem
- **Passive Mobs**: Pig, Cow, Sheep, Chicken, Villager

### Information for Each Mob:
- Health (hearts)
- Attack damage by difficulty (Easy/Normal/Hard)
- Items they drop
- Where they spawn
- XP rewards
- Pro tips and strategies
